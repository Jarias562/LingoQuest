# 🦉 LingoQuest

### By Mr. Arias

**Every Word is an Adventure.**

LingoQuest is an interactive English-learning application designed to make learning English fun, engaging, and accessible for children, teenagers, and adults.

## 🎮 Features

- 📚 English lessons
- 🧠 Multiple-choice activities
- 🎧 Listening practice
- 🎤 Pronunciation practice
- 🧩 Matching activities
- ✏️ Fill-in-the-blank exercises
- ⭐ XP and rewards
- 🪙 Coins
- 🔥 Learning streaks
- 🏆 Badges
- 🗺️ Adventure Map
- 🦉 Questy — our English-learning companion
